A feature exists at the level its evidence supports.

A function name, interface, configuration value or roadmap entry does not prove a working integration. This portfolio uses visible evidence labels so visitors can distinguish tested source behavior, packaged software, simulations and systems that remain external.

Source tested

Execution path inspected

Relevant source and tests were inspected and the isolated tests passed. This does not prove deployment or physical-machine acceptance.

Package evidenced

Artifact identity exists

An accepted package, release record or local publication identity was found. This does not prove current installation or use.

Sanitized simulation

Public behavior is isolated

The browser experience uses invented fixtures and cannot contact company systems, printers or machines.

External not demonstrated

Boundary was traced

The software interface is implemented, but the ERP, share, machine, licensed CAD/CAM application or peripheral was not exercised.

Experimental

Not production truth

Code exists, but cutover, required inputs, reference integrity, packaging or acceptance remains incomplete.

Audited verification

What the October 21 review established

A targeted manufacturing test set covering registry contracts, guarded DXF recipes, atomic geometry output, direct nesting/TAP, dual CNC generation, exact production requests, routing, control authority, telemetry and station behavior completed with 327 passing tests.

A separate CAD/AutoCAD/Fusion transfer repository produced 164 passes and four current failures: two host Tk/runtime failures and two frozen-reference/evidence mismatches. It is therefore shown as experimental/transfer tooling rather than a mature production integration.

Important semantic boundaries

  • Generated is not released.
  • Released is not loaded.
  • Loaded is not physically run.
  • Controller-observed is not automatically completed.
  • A package record is not proof of current deployment.
  • A sanitized demo is not connected to production.
Not exercised

External systems

The review did not run against live ERP SQL, production SMB shares, CNC controllers, EnRoute, AI Center, bSolid, AutoCAD, Fusion, RazorGage, printers or scanners.
