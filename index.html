Standalone product

The whole warehouse on one map.

Warehouse Floor draws a facility as one connected building—departments, walls, doors, racks and floor zones—and ties every count to the exact bay and level where the stock sits.

Layout changes go into a draft and only reach the working map after a review. Counting, pallet moves and stock search all happen on the same map, so nobody has to translate between a spreadsheet and the floor.

Read the case study
01
Layout editor

Move, rotate and add racks in a draft, with undo, redo and a plain-language review before anything is applied.

02
Bay-by-bay counts

Open a rack, record one or several products per bay, and keep "checked empty" separate from "not counted yet."

03
Pallets and search

Pallets carry their contents as they move across the floor; search jumps straight to the bay that holds an item.

About the work

Software for the points where manufacturing handoffs usually become fragile.

My work focuses on practical constraints: existing ERP behavior, mixed-age Windows machines, network interruptions, proprietary formats, operator adoption and the need to recover safely when an external dependency fails.

What this portfolio shows

Inputs, transformations, outputs, refusal behavior and evidence—not only finished screens.

What it does not claim

A passing test or generated file is not automatically a safe physical cut or a live deployed integration.
