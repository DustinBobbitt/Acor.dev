Production traceability

An exact request becomes a frozen plan and verified receipt.

Production requests select explicit job and item identities, capture a plan hash, reject stale or duplicate intent, and verify each generated artifact before recording the result.

Station handoff

Programs move to a station as a transaction, not a loose file copy.

Station applications keep source identity, stage complete sets, preserve the previous local state and roll back an interrupted load. Operators remain in control of the physical machine cycle.

About the work

Software for the points where manufacturing handoffs usually become fragile.

My work focuses on practical constraints: existing ERP behavior, mixed-age Windows machines, network interruptions, proprietary formats, operator adoption and the need to recover safely when an external dependency fails.

What this portfolio shows

Inputs, transformations, outputs, refusal behavior and evidence—not only finished screens.

What it does not claim

A passing test or generated file is not automatically a safe physical cut or a live deployed integration.
